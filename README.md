## 先读这个

ZJE 的中文毕业论文不是从零写中文论文。你已经在 IBMS10008 写过英文 dissertation，中文论文的主线是：

```text
IBMS10008 英文论文
  -> 翻译/迁移为中文第一部分
  -> 填入附件8
  -> 加上 Project Preview 的第二部分材料
  -> 填附件表格
  -> 生成查重版 / BB 电子版 / 纸质存档版
```

当前已按 `examples/ZJE本科生中文毕业论文材料编写指导(中国籍学生专场)260506.pdf` 交叉核对。若文件之间冲突，优先级按：

1. BB 最新通知和学院现场要求
2. `examples/ZJE本科生中文毕业论文材料编写指导(中国籍学生专场)260506.pdf`
3. `examples/中文论文材料顺序-全局索引.xlsx`
4. 本 README、`SKILL.md`、`references/`

关键时间点：

| 事项 | 时间 |
|------|------|
| Project Preview 材料完成 | 2026年2月28日前 |
| 中文论文电子版提交 | 2026年5月15日中午12点 |
| 纸质版提交 | 2026年5月29日中午12点 |
| 学校格式检查 | 2026年6月10日前 |
| 查重要求 | 知网查重率 <= 10%，原则上仅 1 次 |

## 三个版本先分清

| 材料 | 查重电子版 | BB 电子版 | 纸质存档版 |
|------|------------|-----------|------------|
| 大封面 | 需要 | 需要 | 需要，单面 |
| 承诺书 | 不需要 | 需要，可暂不签 | 需要，单面，必须签 |
| 致谢 | 需要 | 需要 | 需要，单面为主 |
| 中文摘要 / 英文摘要 | 需要 | 需要 | 需要，各 1 页单面 |
| 第一部分目录 | 需要，只列实际纳入内容 | 需要 | 需要 |
| 第一部分封面 | 需要 | 需要 | 需要，单面 |
| 第一部分正文 | 需要 | 需要 | 需要，双面 |
| 参考文献 | 不需要 | 需要 | 需要 |
| 作者简历 | 不需要 | 需要 | 需要 |
| 第二部分封面 / 目录 / 正文 | 不需要 | 需要 | 需要 |
| 任务书、考核表、指导教师具体要求 | 不需要 | 不需要 | 需要 |
| 查重报告、专家评阅意见、答辩记录表 | 不需要 | 不需要 | 需要 |

一句话记忆：

- 查重版只放第一部分主体包：大封面、致谢、目录、中英文摘要、第一部分封面、第一部分正文。
- BB 电子版放第一部分完整内容和第二部分正文，不放内部归档表格。
- 纸质版按全局索引把全部材料装订成册。

## 傻瓜式 23 步流程

每一步都按「做什么 -> 用哪个文件 -> 怎么做 -> 检查什么 -> 建议」执行。不要跳步骤。

### 步骤 0：先打开全局索引

做什么：确认整本中文论文有哪些材料、顺序是什么、三个版本分别要放什么。

用哪个文件：
- `examples/中文论文材料顺序-全局索引.xlsx`
- `examples/ZJE本科生中文毕业论文材料编写指导(中国籍学生专场)260506.pdf`

怎么做：
- 先看 Excel 里的材料顺序和版本列。
- 再看 260506 PDF 的 01-21 部分，确认每个附件怎么填。
- 把自己已有材料列成清单：英文论文、Preview 文献综述、Preview 开题报告、feedback、图表、参考文献。

检查什么：
- 知道查重版不含第二部分。
- 知道 BB 电子版不含任务书、考核表、指导教师具体要求、查重报告、专家评阅意见、答辩记录表。
- 知道纸质版需要全部材料。

建议：先不要改模板格式。任何模板里的字号、边距、表格结构，默认都不要动。

### 步骤 1：确认 Project Preview 已完成

做什么：准备第二部分的英文材料。

用哪个文件：
- 自己的 Project Preview 文献综述
- 自己的 Project Preview 开题报告
- BB 上的 Preview feedback

怎么做：
- 找到最终版 Literature Review。
- 找到最终版 Research Proposal。
- 下载或复制 BB 上的 Project preview feedback。

检查什么：
- 文献综述至少有背景、研究现状、研究展望、参考文献。
- 开题报告至少有背景、研究内容与技术路线、进度安排、参考文献。
- 如果 Preview 主题和最终 dissertation 有偏差，后面可以适当改到一致。

建议：不要把 Preview 翻译成中文。文献综述和开题报告在第二部分里保留英文原文。

### 步骤 2：填写附件2第二部分正文

做什么：把 Preview 内容放入第二部分模板，并准备外文翻译；同时准备附件2里的“指导教师对文献综述和开题报告的具体要求”。

用哪个文件：
- `examples/附件2-第二部分模板-文献综述开题报告外文翻译.doc`
- `examples/第二部分正文编写说明-文献综述开题报告外文翻译规则.pdf`
- `examples/附件2-第二部分封面-格式说明.pdf`

怎么做：
- 按顺序填：文献综述 -> 开题报告 -> 外文翻译 -> 外文原文。
- 文献综述和开题报告用英文原文。
- 外文翻译找一篇与毕设课题相关、正式期刊发表的研究性论文，自行翻译成中文。
- 外文原文放在译文后面，可粘贴文字或清晰截图。
- “指导教师具体要求”页填写最终中文题目，从 Project Description 或 Preview guidance 中摘英文原文，或请导师提供中英文要求。
- 指导教师具体要求日期填 2026年1月12日，导师签名可电子签或手签。

检查什么：
- 顺序不能换。
- 外文翻译不能选综述，不能选会议论文。
- 第二部分正文中文用仿宋，英文用 Times New Roman，1.5 倍行距。
- 各章之间分页。
- 指导教师具体要求页不进查重版，也不进 BB 电子版，只进纸质版。

建议：外文翻译没有硬性字数，但要完整真实。不要只翻摘要。

### 步骤 3：填写附件1任务书

做什么：准备纸质版要用的任务书。

用哪个文件：
- `examples/附件1-毕业论文任务书-空白表格.docx`
- `examples/附件1-毕业论文任务书.pdf`

怎么做：
- 题目填最终中文题目。
- 进度安排及任务要求从 Project Description 或导师给的 project guidance 里摘英文原文。
- 起讫日期填 2026年1月12日至2026年4月12日。
- 日期填 2026年1月12日。
- 系或研究所审核意见不填。

检查什么：
- 控制在 1 页。
- 导师姓名、职称、题目和封面一致。
- 不要改模板表格结构。

建议：任务书不进查重版，也不进 BB 电子版，只进纸质版。

### 步骤 4：填写附件11毕业论文考核表

做什么：准备纸质版的毕业论文考核表。

用哪个文件：
- `examples/附件11-毕业论文考核表.pdf`

怎么做：
- 导师评语联系导师写，中英文均可。
- 导师签名日期填 2026年5月15日。
- 答辩小组评语粘贴 BB 上 Oral Presentation feedback 原文，不翻译。
- 成绩和答辩小组签名不填。
- 答辩小组评语日期填 Oral Presentation 当天实际日期。

检查什么：
- 评语真实，和本人论文相关。
- 控制在 1 页。
- 不要填成绩。

建议：先把 feedback 单独存成文本，避免 Word 复制时带入乱格式。

### 步骤 5：填写附件3文献综述和开题报告考核表

做什么：准备纸质版的 Preview 考核表。

用哪个文件：
- `examples/附件3-文献综述和开题报告考核表-空白表格.docx`
- `examples/附件3-文献综述和开题报告考核表.pdf`

怎么做：
- 粘贴 BB 上 Preview 课程的 Project preview feedback 原文。
- 日期填 2026年2月28日。
- 成绩、签名不填。

检查什么：
- feedback 不翻译、不改写、不编造。
- 控制在 1 页。
- 无页眉、无页脚、无页码。

建议：这个表不进查重版，也不进 BB 电子版。

### 步骤 6：确认英文 dissertation 是最终版

做什么：锁定中文迁移的源文件。

用哪个文件：
- IBMS10008 英文 dissertation 最终版 Word 或 PDF

怎么做：
- 确认英文标题、作者、导师、Abstract、Acknowledgement。
- 确认 Introduction / Methods / Results / Discussion / Conclusion 都是最终版。
- 确认图表、参考文献、补充材料是否要迁移。

检查什么：
- 不要拿旧稿翻译。
- 章节标题要后续翻译成中文标题。
- References 和作者简历不进查重版，但 BB 和纸质版需要。

建议：先复制一份英文论文到项目工作目录，只读保存，避免后面找不到源头。

### 步骤 7：填写附件6承诺书

做什么：准备承诺书。

用哪个文件：
- `examples/附件6-承诺书-空白表格.docx`

怎么做：
- 按模板原文填写个人信息。
- 电子版可用电子签或暂不签。
- 纸质版必须作者和导师签名。

检查什么：
- 标题华文仿宋三号。
- 正文仿宋四号，1.5 倍行距。
- 承诺书单独成页，清除页眉，页脚只有居中罗马页码 I。

建议：查重版必须删除承诺书。

### 步骤 8：撰写致谢

做什么：把英文 Acknowledgement 迁移为致谢。

用哪个文件：
- 英文 dissertation 的 Acknowledgement

怎么做：
- 翻译为中文，或按学院允许保留中英文表达。
- 标题居中。
- 正文首行缩进 2 个字符。

检查什么：
- 标题仿宋三号。
- 正文仿宋小四，1.5 倍行距。
- 无页眉，罗马页码连续。

建议：不要套网络模板。致谢要短、真、和自己毕设经历相关。

### 步骤 9：撰写中文摘要

做什么：把英文 Abstract 压缩翻译为中文摘要。

用哪个文件：
- 英文 dissertation 的 Abstract

怎么做：
- 写 300-600 字。
- 覆盖研究背景、目的、方法、核心结果、结论。
- 关键词 3-8 个。

检查什么：
- 控制在 1 页。
- 不放图表、数学公式、参考文献引用。
- 不写第一人称，不用口语表达。

建议：中文摘要不是逐句翻译。优先让结果和结论清楚。

### 步骤 10：整理英文摘要

做什么：保留英文 Abstract，并和中文摘要对应。

用哪个文件：
- 英文 dissertation 的 Abstract

怎么做：
- 标题写 Abstract。
- 正文用英文原文或按中文摘要对应关系微调。
- Key words 3-8 个。

检查什么：
- Times New Roman 三号标题。
- Times New Roman 小四正文，1.5 倍行距。
- 控制在 1 页。

建议：如果中文摘要压缩过，检查英文摘要不要和中文摘要逻辑冲突。

### 步骤 11：生成第一部分目录

做什么：生成查重版、BB 版、纸质版都要用的第一部分目录。

用哪个文件：
- 第一部分正文 Word 文件

怎么做：
- 目录标题写“目录”。
- 根据实际纳入内容生成目录。
- 查重版目录只列查重版实际包含的内容。

检查什么：
- 目录层级和正文标题完全一致。
- 查重版目录不要列第二部分、任务书、考核表、参考文献、作者简历。
- 纸质版目录中任务书、考核表等可列入，但不标页码，也不加引导线。

建议：最后输出前再刷新一次 Word 目录，不要过早手填页码。

### 步骤 12：准备大封面和第一部分封面

做什么：做封面页。

用哪个文件：
- `examples/附件8-大封面-格式说明.pdf`
- `examples/附件8-第一部分封面-格式说明.pdf`
- `examples/附件8-第一部分封面+大封面-格式参考.pdf`

怎么做：
- 大封面填中文题目、姓名、学号、导师、专业、日期。
- 第一部分封面按模板写“第一部分 毕业论文（设计）”。
- 学院名称必须写“浙江大学爱丁堡大学联合学院”。
- 专业只写官方名称：生物医学 / 生物信息学。

检查什么：
- 封面无页眉、无页脚、无页码。
- 题目和所有表格完全一致。
- 不要直接用空白模板提交。

建议：封面最容易出低级错误，最后打印前逐字核对姓名、学号、题目、导师。

### 步骤 13：迁移第一部分正文

做什么：把英文 dissertation 正文翻译成中文论文正文。

用哪个文件：
- `examples/附件8-第一部分模板-毕业论文主体.doc`
- 英文 dissertation 最终版

怎么做：
- Introduction -> 绪论或对应中文章名。
- Methods -> 材料与方法或对应中文章名。
- Results -> 结果。
- Discussion -> 讨论。
- Conclusion -> 结论。
- 英文章节标题直接翻译，不必强行套固定中文标题。

检查什么：
- 章标题仿宋三号加黑。
- 节标题小三号仿宋加黑。
- 子节标题四号仿宋加黑。
- 中文正文仿宋小四，英文 Times New Roman 小四，1.5 倍行距。
- 各章另起一页。
- 奇数页眉为论文题目居右，偶数页眉为“浙江大学本科生毕业论文（设计）”居左。
- 页脚阿拉伯数字连续编码。

建议：不要使用“仿宋GB2312”。不要依赖格式刷批量套格式。

### 步骤 14：整理参考文献

做什么：准备 BB 电子版和纸质版的参考文献。

用哪个文件：
- 英文 dissertation References
- `references/reference_rules.md`

怎么做：
- 全文选择一种引用制度：顺序编码制或著者-出版年制。
- 按 GB/T 7714-2015 统一格式。
- 正文引用和文末参考文献一一对应。

检查什么：
- 不伪造文献。
- DOI、期刊、年份、作者有来源。
- 查重版删除参考文献。

建议：如果时间紧，先保证引用和参考文献对应，再微调格式。

### 步骤 15：撰写作者简历

做什么：准备 BB 电子版和纸质版末尾的作者简历。

用哪个文件：
- 附件8模板中作者简历位置或学校示例

怎么做：
- 写姓名、学号、专业、教育经历、必要的项目经历。
- 放在参考文献之后，另起一页。

检查什么：
- 信息真实。
- 不进入查重版。
- BB 和纸质版需要保留。

建议：简历短即可，不要写成求职简历。

### 步骤 16：完成外文翻译

做什么：完成第二部分中的外文翻译和外文原文。

用哪个文件：
- `examples/第二部分正文编写说明-文献综述开题报告外文翻译规则.pdf`
- 选定的外文研究论文

怎么做：
- 选一篇和毕设主题相关的正式期刊研究论文。
- 翻译为中文。
- 原文放在译文后。

检查什么：
- 不是综述。
- 不是会议论文。
- 译文完整，原文清晰可查。

建议：提前和导师确认选文是否合适，避免翻完后发现类型不符合。

### 步骤 17：准备查重专用版

做什么：生成只用于知网查重的 Word 文件。

用哪个文件：
- 第一部分最终 Word 文件

怎么做：
- 保留：大封面、致谢、目录、中英文摘要、第一部分封面、第一部分正文。
- 删除：承诺书、参考文献、作者简历、任务书、附件11、附件2指导教师具体要求、第二部分全部内容、附件3、查重报告、附件9、附件10。

检查什么：
- 文件不是 PDF。
- 目录只列实际保留内容。
- 正文不含参考文献和简历。

建议：查重版单独另存，不要在总文档上直接删。

### 步骤 18：提交知网查重

做什么：提交查重版。

用哪个地址：
- http://check.cnki.net/pmlc/

怎么做：
- 选择学生入口。
- 用户名填学号。
- 密码为 `zje` + 身份证后 8 位；如果第 9 位是 X，用大写 X。
- 上传 Word/WPS Word 文件。

检查什么：
- 查重率 <= 10%。
- 原则上只有 1 次机会。

### 步骤 19：保存并打印查重报告

做什么：保存查重结果，准备纸质版附件。

用哪个文件：

检查什么：

- 查重率低于 10%。
- 查重报告不进 BB 电子版，只进纸质版末尾附件区。

### 步骤 20：填写专家评阅意见表

做什么：准备纸质版专家评阅意见。

用哪个文件：
- `examples/附件9-专家评阅意见表-空白表格.doc`
- `examples/附件9-专家评阅意见表.pdf`

怎么做：

- 评阅意见粘贴 Dissertation feedback 原文，不翻译。
- 同意答辩处填“√”。
- 评阅人信息不填。

## 红线

| 红线 | 为什么 |
|------|--------|
| 查重率必须 <= 10% | 超过可能影响毕业 |
| 查重版不能用 PDF | 系统可能识别乱码 |
| 查重版不能含承诺书、参考文献、简历、第二部分 | 会影响重复率和版本合规 |
| 第二部分顺序不能换 | 格式检查会出问题 |
| 反馈原文不能翻译或编造 | 内容真实性问题 |
| 学院名称不能简写 | 封面和表格信息不合格 |
| 不要修改模板原始格式 | 全校模板要求统一 |
| 所有导师签名必须是同一位主导师 | 必须与封面指导教师一致 |

## 常用命令

本仓库是 Markdown/Word 文档工作流，不是传统软件项目。脚本只辅助 Word/XML 处理。

```bash
# 初始化一个论文项目目录
python scripts/init_thesis_workspace.py /path/to/new_project

# 从 09_state/current_working.xml 生成 Word
python scripts/build_new_docx.py /path/to/project --name output.docx

# 校验生成的 DOCX
python scripts/validate_xml_docx.py /path/to/project

# 格式化参考文献
python scripts/reference_tools.py format /path/to/refs.json --style "GB/T 7714"
```

依赖：

- Python 3.10+
- `lxml`
- LibreOffice 或可用的 Word 转换工具，用于 `.doc` 转 `.docx`
