# ZJE 官方材料索引

本目录存放 ZJE 本科中文毕业论文相关的官方模板、说明 PDF 和参考材料。学生操作流程已合并到仓库根目录 `README.md`，本文件只保留材料索引，避免同一套时间线在多个 Markdown 文件中重复维护。

使用顺序：

1. 先看 `../README.md` 的 23 步流程。
2. 再按本索引打开对应附件或说明文件。
3. 若本索引、README 和官方文件冲突，以 BB 最新通知、260506 指导 PDF、全局索引 Excel 为准。
